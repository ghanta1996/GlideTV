# Scene pack changelog

Scene packs and the catalogue use independent semantic versions. Once published, a pack's version identifies immutable artwork. Increase the pack version whenever its files or rendering kind change. Increase the catalogue version for changes to pack selection, coverage, or available versions.

## Catalogue 1.0.0

- First downloadable scene catalogue.
- Generic fallback for places without a dedicated city pack.
- Geographic matching uses the nearest eligible pack within its coverage radius.

## Open Horizon 1.0.0

- A shared cloud texture for the native moving landscape.
- Weather, daylight, terrain motion, and precipitation are rendered by the launcher.

## Abu Dhabi Skyline 1.0.0

- Generated day/night panorama and cloud texture.
- Optional city pack covering the Abu Dhabi area; it is not the launcher's default location.
